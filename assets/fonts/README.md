# Bundled fonts

The interface fonts from the approved mockup, bundled so the look is the same
on every OS (P15). All are under the SIL Open Font License 1.1 (compatible with
GPL-3.0-or-later); the licence texts sit next to the files.

| File | Font | Licence |
|---|---|---|
| `Archivo-Variable.ttf` | Archivo (variable: width, weight) | `OFL-Archivo.txt` |
| `IBMPlexSans-Variable.ttf` | IBM Plex Sans (variable: width, weight) | `OFL-IBMPlex.txt` |
| `IBMPlexMono-Regular.ttf`, `IBMPlexMono-Medium.ttf` | IBM Plex Mono | `OFL-IBMPlex.txt` |

Source: the Google Fonts repository (`ofl/archivo`, `ofl/ibmplexsans`,
`ofl/ibmplexmono`).
